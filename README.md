# Multi-Step Checkout

Форма оформления заказа в несколько этапов с валидацией, фейковым бэкендом и отправкой подтверждения на email.

## Статус реализации (~25%)
- [x] Инициализация проекта на React + TypeScript + Vite + SCSS Modules.
- [x] Настроена базовая дизайн-система и переиспользуемые UI-компоненты (`Button`, `Input`).
- [x] Архитектура многошаговой формы (`CheckoutForm`).
- [x] Реализован Шаг 1: Сбор личных данных (Имя, Фамилия, Email, Телефон).
- [ ] Шаг 2: Адрес доставки.
- [ ] Шаг 3: Способ оплаты.
- [ ] Шаг 4: Подтверждение заказа и сводка.
- [ ] Фейковый бэкенд с имитацией задержки и отправки email на указанный адрес.

## Запуск проекта

```bash
npm install
npm run dev
```
